# Matrikkel actions

Dette repoet inneholder GitHub actions tilhørende matrikkelen som har behov
utvidede tilganger. Repoet har tilgang til en `matrikkel-deploy` service
account som har utvidede rettigheter (på bl.a. SKIP) gjennom workload identity
federation. For å unngå utilsiktede hendelser er administrator- og
skrivetilgang i repoet begrenset.
